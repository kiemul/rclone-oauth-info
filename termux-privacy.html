Privacy policy

Effective 10 October 2026

This is a personal Google OAuth client used with rclone and related local command-line workflows in Android Termux. It is not offered as a hosted service to other users.

Access and purpose

The owner can authorise full Google Drive access, which permits the local rclone program to view file names, metadata and contents and to download, upload, move, rename or delete Drive files. These permissions support personal backup, syncing and file management requested by the account owner. The program does not perform such modifications merely because OAuth was granted.

Data storage and sharing

Authorisation credentials and any files or metadata processed by rclone are handled locally on the owner's devices or within the Google Drive account itself, as directed by the owner. This GitHub Pages disclosure website does not collect Google user data, store OAuth tokens, serve user files or sell/share Drive data with advertisers.

Revocation and security

The owner may stop using this integration, delete local rclone configuration or revoke its permission at Google Account connections. Tokens are stored in private local rclone configuration and are not posted on this public website.

Updates

Any material change to how this personal integration accesses, uses or shares Google user data should be reflected in this privacy policy.
