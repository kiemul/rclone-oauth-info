Privacy policy

Effective 10 October 2026

This OAuth application is a privately operated Google Drive connection used with the open-source rclone program on the account owner's devices. It is not a public hosted service.

Google user data accessed

With the owner's explicit OAuth permission, rclone can access Google Drive file metadata, including file names, paths, sizes, checksums and identifiers. The current connection requests only the Google Drive metadata read-only OAuth scope. It cannot use this scope to read file contents or change files.

Use of data

The owner uses that metadata locally to list, organise and identify exact duplicates of their own Google Drive files. Authorisation credentials and locally produced metadata reports reside on the owner's device. This static website does not receive or store Drive data, credentials or user uploads.

Sharing and transfers

Google user data retrieved through this personal OAuth integration is not sold, shared with advertisers or transmitted to a third-party analytics service by this site. The rclone program communicates with Google's APIs to fulfil the owner's requested operations.

Storage and deletion

The owner controls any locally stored rclone configuration and scan reports and can delete them from their own devices. Google account access may be revoked at Google Account connections. The website itself retains no Google Drive metadata.

Security

OAuth tokens are kept in local rclone configuration; they are not committed to this public repository. This website contains only disclosure documents. The owner is responsible for safeguarding access to their devices and credentials.

Changes

Any additional permissions or changes to data handling should be reflected in this document before further authorisations.
