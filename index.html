What is this?

This is the information page for a privately operated OAuth client named Rclone Drive Readonly. It authorises rclone, an open-source command-line tool, to work with the owner's own Google Drive account.

What does it do?

The current integration requests Google Drive metadata read-only permission. It lists file names, sizes, Google Drive file IDs and existing checksums to identify exact duplicate files. It cannot read file contents, upload files, rename them or delete them using this permission.

Rclone runs locally on the account owner's own devices. The public information pages here do not accept logins, process Google Drive data or store OAuth access tokens.

Who can use it?

The OAuth client is intended for the owner's personal use, not offered as a hosted third-party service.

See the privacy policy for the handling of Google user data.
